# skills
paper-bilingual-html

请把下面这篇论文翻译成【中英对照版 HTML】，严格仿照我给的示例文件排版。

## 输入
- 待翻译论文 PDF：`<PDF 路径>`
- 格式示例：`<示例 HTML 路径>`（先读它，完整复用它的 CSS、JS 和页面结构）

## 输出要求（必须逐条满足）
1. 输出一个独立、自包含的 HTML 文件（内联 CSS/JS，无外部依赖），命名 `<原论文名>_中英对照.html`。
2. 完整复用示例的：工具栏（中英对照/仅中文/仅英文切换、上下对照、字号 A−/A+、打印导出 PDF）、阅读进度条、左侧吸附目录、术语表、页脚。
3. 页面结构顺序：期刊/DOI 眉题 → 中文标题 + 英文标题 → 作者 → 单位（逐条中英对照）→ 摘要 → 关键词 → 正文各节 → 图表 → 参考文献 → 术语对照表。
4. 正文【逐段】中英对照：每个段落用示例里的 `.pair` 双栏（左英文 `.en`、右中文 `.zh`），不要整篇打包翻译。
5. 图表：从 PDF 提取【原图】，转成 JPEG 后以 base64 内嵌（不要外链、不要占位图、不要用文字描述替代）；每幅图配双语图题。
6. 参考文献：保留完整英文原文条目，并【逐条】给出题名中文译文；作者/期刊/卷期页码保留原文。
7. 术语表：抽取本文 15~25 个专业术语，中英对照。

## 关键约束与常见坑（务必遵守）
- PDF 多为两栏排版，提取文字时要【先读左栏、再读右栏】，避免左右栏串行。
- 作者中文名：只在你 100% 确定时才音译（如成秋明），不确定的保留拼音，不要乱猜。
- 数值、公式、指标（R²、Kappa、Δθ、SSC 等）、引用 `(作者, 年份)` 一律保留原文不改写。
- 图片若为 jpx/jpeg2000 需先转 PNG/JPEG 再内嵌，控制总文件在几 MB 内。
- 若正文引用但参考文献页提取不全的条目，用译注标注「以原刊为准」，不要杜撰卷期页码。
- 生成后启动本地 HTTP 服务预览校验：确认图片显示、目录跳转、三种语言模式切换正常。
